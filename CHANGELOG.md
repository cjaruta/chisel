# Changelog

## 1.0.0 - unreleased

First release: a Windows desktop daily planner with a customizable widget dashboard (schedule, clock, tasks, notes, quick
links, weather, calendar, habits, countdown, focus timer, media, pictures, clipboard history and more), stored in local SQLite.

- Backup and restore to one JSON file, with replace or merge and an automatic undo point.
- System, light and dark themes; the window remembers its monitor, size and maximized state.
- Damaged data is kept as a .bad copy and Chisel starts fresh instead of failing.
- Crash reports with no personal data, and copyable diagnostic info in Settings > Help.
