# Screenshots

The main README shows these once they exist. Capture them from a real window at 100% display scaling, about
1200 x 760, and save them as PNG with these names:

| File | What to show |
| --- | --- |
| `dashboard.png` | The default dashboard in the light theme: schedule, tasks, notes, clock and weather. |
| `widget-library.png` | Edit mode with the widget library open. |
| `settings.png` | Settings on the Appearance tab (theme, accent color, widget spacing). |
| `stopwatch-faces.png` | The clock widget with the analog stopwatch showing, ideally with laps. |
| `dark-theme.png` | The dashboard in the dark theme with a few more widgets (focus timer, habits, countdown). |

Use sample content only, such as the starter dashboard or made-up tasks and notes ("Write the weekly plan", "Test User").
Before capturing, check that nothing personal is visible: real names, emails, your weather location, clipboard history,
notes text, picture-frame photos, media titles, file paths in quick links, or the taskbar and other windows.
