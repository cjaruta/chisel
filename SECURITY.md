# Security

Please report security problems privately, not as a public issue: use GitHub's
[private vulnerability reporting](https://github.com/cjaruta/chisel/security/advisories/new) for this repository.

Include what you found, how to reproduce it, and which version you used (Settings > Help > About). You'll get a reply
as soon as possible, and a fix will be released before details are made public.

Only the latest release gets security fixes.
